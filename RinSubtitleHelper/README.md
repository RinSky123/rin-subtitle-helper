# Rin 字幕效果助手

**by RinSky123 · 此脚本完全免费使用，请勿倒卖**

一个从零实现的 After Effects **CEP 面板扩展**，用来批量做字幕卡点 / 逐字动画 / 发光流光。

导入一份 SRT，它会按时间码批量生成文字图层，然后一键套用字体、颜色、出入场动画、流光、发光。

**免授权、免联网、无加壳、无外部依赖**，装好即用。

**版本 v1.13.1**（面板右上角会显示，以面板里的为准）

## 功能

| 模块 | 说明 |
|---|---|
| **SRT 导入** | 读取 `.srt`，按时间码批量生成文字图层（每条字幕一个图层，自动裁剪入/出点），可选自动预合成。**每条自动延长 N 帧**（默认 50），可开关强制大写 / 清洗标点 |
| **句 / 词 / 字符 动画** | 用 AE 原生 Text Animator + Range Selector 实现，默认字符级「从左到右逐字擦除」 |
| **出入场按帧调节** | 入场基准 **1.5 秒**（±60 帧）、出场基准 **35 帧**（10~50 帧）。滑块是帧偏移，卡点不会因帧率漂移，面板实时显示换算结果 |
| **出场渐隐（强制）** | **任何入场都渐显、任何出场都渐隐**，整层透明度与逐字动画同一时间窗口，两条字幕交叠时新的那条不会被糊住 |
| **出场时间轴** | 从**原 SRT 出点**开始匀速淡出，淡完正好到出点，延长段不会"全亮空转" |
| **新旧交叠** | 旧字幕开始渐隐的那一刻，新字幕正好开始入场 |
| **持续放大** | 从入场开始一直放大到出场结束，字间距同步拉开（面板默认 6 ≈ 实际 +10%）。只要有动画就自动生效 |
| **文字颜色** | 单色，或**每条字幕一个颜色、相邻不重复**（洗牌轮转）。条形横杠直接取色，可存预设 |
| **流光** | 让颜色在文字上像水一样流动，四种模式：**光带** / **晕染留白** / **全范围晕染留白** / **彩带**。全部用分形噪波实现，**多行字幕同时染色**。有开关、模式、周期、留白处数 |
| **发光** | 优先调用 Deep Glow 2（**中英文版都能写参数**），未安装时自动退回 AE 自带 Glow；半径 / 曝光 / 灯光强度可调，发光色有独立调色区。文字为白色时用发光色设置，文字为其它颜色时自动跟随文字颜色 |
| **双层投影（强制）** | **只要做了发光，两层投影必然存在**：发光前（100% / 135° / 距离5 / 柔和2）+ 发光后（90% / 135° / 距离5 / 柔和20）。顺序固定 `投影1 → 发光 → 投影2` |
| **字体** | 扫描系统已安装字体（解析字体文件二进制取 PostScript 名）；每条字幕一个字体、相邻不重复 |
| **实时预览** | 动画预览（④）演示出入场 + 颜色 + 流光（逐字推进、5 秒无缝循环）；发光预览（③）演示发光 + 双层投影。均左英右中双列，实时反映 |
| **字符间距** | 用 Tracking Amount 动画器调节字/词间距 |
| **智能分行** | 超过「分行基准」字数自动折行。**绝不拆单词**、**标点不单独成行**、行首不留收尾标点、行尾不留开引号 |
| **精确数值** | 滑杆旁边的数值可直接输入 |
| **诊断工具** | 「诊断」查动画器、「时序」查标记/出点/淡出区间、「投影值」查效果链、「发光值」查 Deep Glow 实际参数名 |
| **附加** | 图层交错（卡点错开入点）、调整图层、参数预设、恢复出厂 |

> **波浪**已接入 AE 的 Wave Warp，但效果尚不完善，面板上标注了「暂不推荐使用」。

> ⚠️ **第二页「随机字幕面板」尚未测试和完善，请勿使用。**
> 随机字体 / 随机颜色 / 随机动画 / 画面与文字等功能仍在开发，效果和时序均未验证。

## 依赖的 AE 插件

**整个脚本只跟一个外部插件打交道，而且是可选的。**

### 唯一的第三方插件（可选）

| | |
|---|---|
| **插件名** | **Deep Glow 2**（作者 Plugin Everything，商业付费插件） |
| **matchName** | `PEDG` |
| **用途** | 发光效果 |
| **是否必须** | **不必须** —— 没装会自动退回 AE 自带的「发光 (Glow)」 |

查找顺序依次是 `PEDG` → `Deep Glow 2` → `DeepGlow2` → `Deep Glow` → `DeepGlow`，
全都找不到时才退回 `ADBE Glo2`（AE 自带发光）。

> ⚠️ Deep Glow 2 的参数名在它的二进制里是加密的，本项目是按关键字（阈值 / 半径 / 曝光 / color）匹配写入。
> 如果你的版本命名不同，**发光颜色**可能设不进去（发光本身正常）。

### AE 自带的效果（全部免费，无需安装）

| 效果 | AE 里的名字 | 用途 |
|---|---|---|
| `ADBE Glo2` | **发光** (Glow) | 发光回退方案 |
| `ADBE Drop Shadow` | **投影** (Drop Shadow) | 自动补的两层投影（发光前一后各一层） |
| `ADBE Wave Warp` | **波浪变形** (Wave Warp) | 波浪效果（在「扭曲」分类） |

这三个都是 AE 内置的标准效果，AE 2022+ 全部自带。

### 文字动画部分不是插件

逐字 / 逐词 / 逐字符的进出场、流光，用的都是**文字图层自带的 Text Animator**，
属于 AE 内置能力，不需要任何插件。

字体也是直接扫描系统字体，**没有字体插件依赖，也不需要联网**。

## 安装

1. 把 **`RinSubtitleHelper` 文件夹整个**复制到：

   | 系统 | 目录 |
   |---|---|
   | Windows | `C:\Program Files\Common Files\Adobe\CEP\extensions\`（**需要管理员权限**） |
   | macOS | `~/Library/Application Support/Adobe/CEP/extensions/` |

   复制完的层级必须是 `extensions\RinSubtitleHelper\CSXS\manifest.xml`，**不能多套一层**。

2. **开启调试模式**（未签名扩展必须开，否则菜单里看不到）：

   **Windows** — 给下面每个版本都新建一个字符串值 `PlayerDebugMode = 1`：
   ```
   HKEY_CURRENT_USER\Software\Adobe\CSXS.11
   HKEY_CURRENT_USER\Software\Adobe\CSXS.12
   HKEY_CURRENT_USER\Software\Adobe\CSXS.13
   HKEY_CURRENT_USER\Software\Adobe\CSXS.14
   ```

   **macOS** — 终端执行：
   ```bash
   defaults write com.adobe.CSXS.11 PlayerDebugMode 1
   defaults write com.adobe.CSXS.12 PlayerDebugMode 1
   defaults write com.adobe.CSXS.13 PlayerDebugMode 1
   defaults write com.adobe.CSXS.14 PlayerDebugMode 1
   ```

3. **完全退出并重启 After Effects**（Windows 上任务管理器里不能有 `AfterFX.exe` 残留），
   菜单里就会出现：`窗口 (Window) → 扩展 (Extensions) → Rin字幕效果助手`

> 环境要求：After Effects **2022 及以上**（Windows / macOS 均可）

## 使用

1. 打开一个合成；
2. **① 字幕**：点 **选择 SRT** → 设置分行基准 / 预合成 → 点 **确定导入**。
   导入只做两件事：按时间码建文字图层 + 预合成，**不施加任何效果**；
3. **②③④⑤** 调字体 / 颜色·发光·流光 / 入场出场 / 波浪，④ 上方实时预览；
4. 点 **一键生成效果**，对当前合成里的文字图层统一套用全部设置。

勾选 **仅对选中图层** 时，只作用在时间线里选中的文字图层上。

**关于字体**：导入字幕时**不会**套用 ② 里的字体。字体统一由 **② → 确认修改字体** 来应用，
这样你可以先导入、调好动画，最后再决定字体。

## 常见问题

**`窗口 → 扩展` 里看不到？**
多半是没开 `PlayerDebugMode`，或 AE 没完全重启。

**字幕是乱码？**
引擎按 UTF-8 读取；若 SRT 是 GBK，用记事本另存为 UTF-8 即可。

**流光看起来没在动？**
周期滑杆调小一点；流光在**文字颜色不是纯白**时最明显。

**投影 / 发光参数不对？**
点「执行」那行的 **投影值** 按钮，状态栏会打印该图层**整条效果链顺序**和两层投影的实际参数，
正常应为 `投影1-发光前 > Deep Glow 2 > 投影2-发光后`。

**参数调乱了想回到最初？**
点「**恢复出厂**」即可回到默认（半径 200 / 曝光 0.32 / 灯光强度 0.4 等），
自己「存为预设」的参数不受影响。

**发光参数不对 / 汉化版没反应？**
点执行区的「**发光值**」按钮，会列出 Deep Glow 的**实际参数名和值**，
一眼就能看出参数有没有写进去。本项目已支持中英文参数名（汉化版也能写入）。

**发光颜色设了没反应？**
先确认文字颜色是**白色**（文字是其它颜色时，发光会自动跟随文字色，发光色设置不生效）。
是白色还没反应，点「**发光值**」按钮，正常应打印出
`Tint: Enable=1 Color=… Mode=3 Mix=100` ——
`Enable=0` 说明 Tint 没打开，请把这一行发给我。
